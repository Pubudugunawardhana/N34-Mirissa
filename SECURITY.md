# Security Policy

## Supported Versions

Only the latest code on the `master` branch receives security fixes.

| Branch   | Supported |
| -------- | --------- |
| `master` | Yes       |
| Others   | No        |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.** Public reports let others exploit the problem before it is fixed.

Report it privately through GitHub instead:

1. Go to the [Security tab](https://github.com/Pubudugunawardhana/N34-Mirissa/security) of this repository.
2. Click **Report a vulnerability**.
3. Fill in the form. Only the maintainer can see your report.

Please include as much of the following as you can:

- The type of issue (for example SQL injection, XSS, broken authentication, exposed secrets)
- The affected file paths, pages, or API routes
- Steps to reproduce the issue
- Proof-of-concept code or screenshots, if available
- The possible impact, and how an attacker could use it

## What to Expect

- **Acknowledgement:** within 3 days of your report.
- **Updates:** you will be kept informed while the issue is investigated and fixed.
- **Disclosure:** please keep the issue private until a fix is released. Once it is fixed, you will be credited in the advisory if you wish.

Thank you for helping keep N34 Mirissa and its users safe.
